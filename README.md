HR Analytics Dashboard
Overview

The HR Analytics Dashboard is an interactive Power BI project developed using the IBM HR Employee Attrition dataset. The dashboard provides meaningful insights into employee attrition by analyzing workforce demographics, job roles, departments, overtime, education fields, and other HR-related factors. It helps HR professionals and business leaders identify patterns affecting employee turnover and supports data-driven decision-making to improve employee retention.

Objectives
Analyze employee attrition across different departments and job roles.
Monitor key workforce metrics using interactive KPI cards.
Identify the impact of overtime, age, gender, and education on employee attrition.
Provide interactive filtering for detailed HR analysis.
Present insights through clear and professional visualizations.
