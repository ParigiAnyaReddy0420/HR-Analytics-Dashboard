# 📊 HR Analytics Dashboard

An interactive HR Analytics Dashboard developed using **Power BI** to analyze employee attrition and workforce trends. This project uses the IBM HR Employee Attrition dataset to provide actionable insights through interactive visualizations, KPI cards, and filters.

---

## 📌 Project Overview

The objective of this project is to analyze employee attrition and identify the key factors influencing workforce turnover. The dashboard helps HR professionals understand employee demographics, departmental performance, job satisfaction, overtime impact, and other HR metrics to support data-driven decision-making.

---

## 🎯 Objectives

- Analyze employee attrition across departments and job roles.
- Monitor workforce KPIs using interactive dashboard cards.
- Identify the impact of age, gender, overtime, and education on attrition.
- Provide interactive filtering for better HR analysis.
- Support HR decision-making with meaningful insights.

## 💡 Key Insights

- The overall employee attrition rate is **16.12%**.
- Research & Development has the highest number of employees.
- Employees working overtime show a higher attrition trend.
- The 26–35 age group experiences the highest employee turnover.
- Certain job roles have significantly higher attrition than others.
